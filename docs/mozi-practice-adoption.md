# 墨知产品实践迁移到墨牍

本次参考 `/Users/yunz/Code/VibeCoding/markdown-press` 当前工作区，基线 `2f6b314`，其中更新服务、发布验证与设置页包含未提交改动。只读参考，不修改墨知。目标项目的实现和验收单独记录，不能以墨知代码存在代替墨牍验证。

| 墨知实践 | 墨牍采用方式 | 边界 |
| --- | --- | --- |
| 恢复完成前不写默认状态 | 原生加载屏障，损坏库进入错误页 | 已有能力保留 |
| 内容与用户事实分离 | SQLite 内容表与阅读状态分开，刷新保留文章 ID | 单设备，无云协调 |
| 保存串行与最终保存 | 单写队列；退出和更新前保存最新正文位置与偏好 | 单窗口，不照搬多窗屏障 |
| 主题语义与独立字体 | 墨知截图精确色值、主题色、界面与正文独立字体 | 按已安装名称选择，不枚举字体 |
| 静默检查与跳过版本 | 检查不夺焦点，不强制弹窗；手动检查仍能发现跳过版本 | 正式渠道，不预建测试版索引 |
| 分阶段更新反馈 | 检查、下载、验签、待安装、最终保存、安装和失败反馈 | 下载完成不冒充安装成功 |
| 取消与失败恢复 | 下载可取消；旧请求失效；保存/安装失败解除交互保护 | 标准更新器负责平台替换 |
| 不透明准备标识 | 前端只持候选 ID，包和更新句柄由 Rust 持有 | 不接受任意安装路径或自带公钥 |
| 受信任发布资产 | 同仓库/版本/架构、签名和签名版本核验 | 墨牍独立密钥；不复用墨知私钥 |
| 候选与公开字节分开验收 | 候选清单检查；发布后重新下载并验证摘要与签名 | 未验证资产不切换稳定入口 |
| 版本单一来源 | tag 同步四份版本元数据，统一生成清单 | 首版仅 macOS arm64 |
| 原生真实验证 | 旧客户端下载安装与重启，检查最新阅读事实保留 | 不用模拟器代替实际应用 |

墨知自定义 macOS 安装脚本固定安装路径，并含隔离属性处理。墨牍使用标准 Tauri 更新器，继承状态、数据保护和验证契约，避免引入这些项目专用假设。全文抓取、分组管理、字体枚举、云同步等属于独立产品范围，本次不因源项目存在而自动加入。
